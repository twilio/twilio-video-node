    Type Alias RoomEvents

    Listener signatures for every event a Room can emit.

    The track events at the end of this map are emitted by each RemoteParticipant and re-emitted here, with the participant that emitted them appended as the last argument. Listening here handles every participant's tracks in one place, instead of attaching listeners to each participant.

    connectFailure

    connectFailure: (error: TwilioError) => void

    The Room could not be joined. Terminal: no further events follow.

    Used internally by connect, which rejects with this error and disposes the partially built Room. Application code never receives a Room on which this can still fire, so failures are handled by catching the rejection from connect.
