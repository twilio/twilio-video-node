    bandwidthProfile?: BandwidthProfileOptions

    Limits on incoming media, controlling how subscribed tracks share bandwidth.

    OptionalconnectionTimeout

    connectionTimeout?: number

    Milliseconds to wait for the Room to connect before giving up. On expiry the promise rejects with a RoomConnectTimeoutError and the partially built Room is disposed. Defaults to 30000. Pass 0 to wait indefinitely.

    OptionaldataTracks

    dataTracks?: LocalDataTrack[]

    Local data tracks to publish on join.

    OptionalenableAutomaticSubscription

    enableAutomaticSubscription?: boolean

    Automatically subscribe to remote participants' tracks. When false, tracks must be subscribed to explicitly.

    OptionalenableDominantSpeaker

    enableDominantSpeaker?: boolean

    Enable dominant-speaker detection, which powers Room.dominantSpeaker and the dominantSpeakerChanged event.

    OptionalenableInsights

    enableInsights?: boolean

    Enable Twilio Insights telemetry for this Room.

    OptionalencodingParameters

    encodingParameters?: EncodingParameters

    Initial send-bitrate limits; equivalent to calling LocalParticipant.setEncodingParameters after connect.

    OptionaliceOptions

    iceOptions?: IceOptions

    Overrides for ICE candidate gathering and transport policy.

    Optionalname

    name?: string

    Room name to connect to. When omitted, the Room SID is used as its name.

    OptionalnetworkQuality

    networkQuality?: boolean | NetworkQualityConfiguration

    Enable network-quality reporting. Pass true for default verbosity (local=1, remote=0) or an object to set verbosities individually. Setting false (or omitting) disables reporting.
